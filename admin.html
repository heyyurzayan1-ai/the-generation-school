How to create a login

1. User opens the public Create Login page and registers with their own email and password.

2. The new account appears below as Parent by default.

3. Admin changes its role to Teacher, Student or Parent, then links the account to its student/class record.

For safety, users set their own passwords. Admin never sees or stores passwords.
